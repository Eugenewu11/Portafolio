## 📋 Descripción  
Este es mi portafolio personal desarrollado con **React y Vite**, diseñado para mostrar mis habilidades como desarrollador Full-Stack.  
El proyecto incluye **animaciones fluidas con GSAP** y **gráficos 3D con OGL** para crear una experiencia visual impactante.  

---

## ✨ Características Principales  
- 🎨 **Diseño Moderno:** Interfaz limpia y profesional  
- ⚡ **Animaciones Fluidas:** Transiciones suaves con GSAP  
- 🎮 **Elementos 3D:** Gráficos WebGL con OGL  
- 📱 **Responsive Design:** Adaptado para todos los dispositivos  
- 🚀 **Alto Rendimiento:** Optimizado con Vite  
- 📄 **Descarga de CV:** Función integrada para descargar currículum  

---

## 🛠️ Tecnologías Utilizadas  
- **Frontend:** React 18, JavaScript ES6+, CSS3  
- **Animaciones:** GSAP 3.x, Framer Motion, Lottie  
- **3D Graphics:** OGL, WebGL  
- **Build Tool:** Vite  
- **Linting:** ESLint  

---

## 🚀 Instalación  

### Prerrequisitos  
- Node.js (versión 16 o superior)  
- npm o yarn  

### Pasos de instalación  

```bash
# Clona el repositorio
git clone https://github.com/Eugenewu11/Portafolio.git

cd Portafolio

# Instala las dependencias
npm install

# Instala dependencias específicas
npm install gsap ogl 

#Ejecuta en modo desarrollo
npm run dev

#Abre en tu navegador:
http://localhost:5173/
```
